# Decisiones de diseño


## Comentarios

Se siguió la estructura general del diseño de la página, apoyandose con la tabla de base de datos SQL para el almacenamiento de los comentarios. Para los avistamientos sin comentarios, se muestra un mensaje en el que dice "Todavia no hay comentarios". Para cuando ya se encuentra alguno, la página muestra el nombre de quien comentó y su comentario respectivo.

## Estadísticas

Para la implementacion de este apartado se importó la bilioteca Flot que se recomendó en el archivo de la tarea. Con ello, se implementarion los gráficos de avistamiento por día, avistamientos por nombre de aves o especie y voluntarios por comuna.
